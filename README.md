# Azure Data Fundamentals (DP-900) Project

## Project Overview

This project was completed as part of the **Microsoft Azure Data Fundamentals (DP-900)** training course and demonstrates foundational knowledge of cloud computing, Azure data services, and modern data analytics solutions. The project explored how data can be stored, processed, ingested, and analysed across multiple Azure platforms, providing hands-on experience with both relational and non-relational data technologies. Based on practical labs involving Data_Technician_Workbook_Week_5.docx, the project included Azure SQL Database, Azure Storage, Azure Cosmos DB, and Microsoft Fabric analytics workloads. 【1-365c85】

## Key Learning Areas

### Cloud Computing Fundamentals
- Understanding cloud computing concepts and benefits, including scalability, high availability, cost efficiency, and security.
- Exploring cloud service models:
  - Infrastructure as a Service (IaaS)
  - Platform as a Service (PaaS)
  - Software as a Service (SaaS)
- Comparing deployment models including Public, Private, Hybrid, and Community Cloud environments.
- Evaluating Azure pricing and resource planning using Azure cost estimation tools. 【1-365c85】

### Relational Data with Azure SQL Database
Worked with **Azure SQL Database** to understand relational database concepts and structured data management.

Key skills demonstrated:
- Creating and querying relational databases.
- Understanding tables, relationships, primary keys, and foreign keys.
- Writing SQL queries to analyse business data.
- Extracting insights from retail and sales datasets using:
  - `SELECT`
  - `WHERE`
  - `ORDER BY`
  - `GROUP BY`
  - `JOIN`
  - Aggregate functions such as `SUM()`, `COUNT()`, and `AVG()`

Example business questions answered:
- Which products generated the highest sales revenue?
- Which regions achieved the greatest number of transactions?
- What were the monthly sales trends?
- Which customers made the most purchases? 【1-365c85】

### Non-Relational Data with Azure Storage and Azure Cosmos DB
Explored Azure services designed for storing and managing unstructured and semi-structured data.

#### Azure Storage Account
- Storing files, documents, and business data.
- Understanding Blob Storage concepts.
- Working with scalable cloud storage solutions.
- Managing data for backup, archival, and analytical processing.

#### Azure Cosmos DB
- Understanding NoSQL database principles.
- Working with JSON document-based data.
- Exploring globally distributed databases.
- Learning when NoSQL solutions are preferable to traditional relational databases.
- Querying and accessing flexible schema data structures. 【1-365c85】

### Analytics with Microsoft Fabric
Developed an understanding of analytical workloads using **Microsoft Fabric**, including modern data engineering and reporting concepts.

Key areas explored:
- Data warehousing and large-scale analytics.
- Working with a Fabric Lakehouse architecture.
- Understanding how structured and unstructured data can coexist within a unified analytics platform.
- Building foundations for reporting and business intelligence.
- Creating insights from enterprise-scale datasets.
- Integrating data for downstream Power BI reporting and visualisation. 【1-365c85】

## Data Ingestion and Processing

The project explored several methods of bringing data into Azure analytics environments, including:

- Event-driven data ingestion using **Microsoft Fabric Eventstreams**.
- Batch ingestion from files stored in Azure Storage.
- Importing CSV and structured datasets into Azure analytics workloads.
- Connecting multiple data sources to support reporting and analysis.
- Understanding real-time and near real-time analytics pipelines.
- Preparing data for transformation and analysis within a Lakehouse architecture.

These activities provided practical experience in designing data pipelines and understanding how data flows through modern cloud-based analytics solutions.
